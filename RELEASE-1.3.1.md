# GlyphCheck 1.3.1

Glyph-name list audits, synchronized article comparison, cross-font supplements/replacements with individual acceptance, and a cleaner native sidebar workbench. This patch also fixes a numeric-type ambiguity when compiling with older Swift toolchains.

## Use

Download the ZIP, extract and open **字形檢查器.app**. Apple silicon · macOS 14+. Ad-hoc signed, not notarized. Existing progress remains readable; originals are never overwritten. No user fonts or third-party character lists are bundled.

Glyphs support is for glyph-name text lists, including named variants—not `.glyphs` design files. Unknown mappings remain unresolved. Cross-font output supports static non-color TrueType targets; source outlines can be TrueType or CFF. Style matching and shaping-table repair are not automatic.
